# Local release checks

The scientific release contains 31 complete reference protocols, 81 recommendation candidate evaluations, 30 locally audited selected checkpoints, 84 valid route results, 14 executed English notebooks and 30 PNG / PDF figure pairs. Twenty tests cover independent numerical oracles and meaningful implementation invariants.

- Original201-file archive preserved byte-for-byte; detected-content manifest public, raw material private.
- Every full reference source binding and configuration checked; initial recommendation source snapshot retained explicitly.
- Public numeric evidence finite, except deliberately masked missing synthetic entries; strict JSON rejects NaN / infinity.
- Lasso / nuclear dual feasibility and gaps, Poisson boundary KKT / objective conventions, physical control / population residuals and portfolio dual mixture checked.
- All tours checked as permutations with cyclic EUC_2D objectives; counted-work caps verified; integer 1-tree witnesses independently recomputed.
- Independent DP / MTZ MILP certify the small subproblem; larger heuristic gaps retained honestly.
- Fresh factor checkpoints reproduce published prediction / error aggregates through portable NumPy inference; raw ratings / factors remain private.
- Source-tree and installed-wheel tests; installed commands verified outside the checkout.
- Clean source archive checked against the frozen checkout and validated with all notebooks in fresh kernels.
- New authored code / prose use MIT; external photograph, Iris and source benchmarks retain separate attribution.
- Local main branch and annotated v1.0.0 tag; no remote publication.

`docs/validation.json`, `docs/checkpoint_audit.json`, `docs/notebook_execution.json` and `docs/release_artifacts.json` record the actual checks. The hosted GitHub Actions workflow is prepared but not represented as an executed hosted run.
