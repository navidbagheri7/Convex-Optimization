# Primary references

- Boyd and Vandenberghe, *Convex Optimization*, Cambridge University Press,2004. [Author-hosted book and course resources](https://web.stanford.edu/~boyd/cvxbook/). The book is referenced, not redistributed.
- Parikh and Boyd, *Proximal Algorithms*,2014. [Author-hosted manuscript](https://web.stanford.edu/~boyd/papers/prox_algs.html).
- Beck and Teboulle, *A Fast Iterative Shrinkage-Thresholding Algorithm*,2009. [DOI](https://doi.org/10.1137/080716542).
- Boyd et al., *Distributed Optimization and Statistical Learning via ADMM*,2011. [Author resources](https://web.stanford.edu/~boyd/papers/admm_distr_stats.html).
- Cai, Candès and Shen, *A Singular Value Thresholding Algorithm for Matrix Completion*,2010. [Paper](https://arxiv.org/abs/0810.3286). The repository solves an explicitly declared penalized masked objective, not a claim of identical original constrained SVT.
- Harper and Konstan, *The MovieLens Datasets: History and Context*,2015. [DOI](https://doi.org/10.1145/2827872). [Official100k dataset](https://grouplens.org/datasets/movielens/100k/) and [downloaded README](https://files.grouplens.org/datasets/movielens/ml-100k/README).
- Koren, Bell and Volinsky, *Matrix Factorization Techniques for Recommender Systems*,2009. [DOI](https://doi.org/10.1109/MC.2009.263).
- Kingma and Ba, *Adam: A Method for Stochastic Optimization*,2015. [Paper](https://arxiv.org/abs/1412.6980).
- Reinelt, TSPLIB95. [Official collection](https://comopt.ifi.uni-heidelberg.de/software/TSPLIB95/), [distance specification](https://comopt.ifi.uni-heidelberg.de/software/TSPLIB95/tsp95.pdf), [proven symmetric optimum table](https://comopt.ifi.uni-heidelberg.de/software/TSPLIB95/tsp/TSP-BEST.html). Berlin52=7542 and ch150=6528; the table was verified from the primary search index when a direct fetch timed out.
- Dorigo and Gambardella, *Ant Colony System: A Cooperative Learning Approach to the Traveling Salesman Problem*,1997. [DOI](https://doi.org/10.1109/4235.585892).
- Kirkpatrick, Gelatt and Vecchi, *Optimization by Simulated Annealing*,1983. [DOI](https://doi.org/10.1126/science.220.4598.671).
- Held and Karp, *The Traveling-Salesman Problem and Minimum Spanning Trees*,1970. [DOI](https://doi.org/10.1287/opre.18.6.1138).
- Miller, Tucker and Zemlin, *Integer Programming Formulation of Traveling Salesman Problems*,1960. [DOI](https://doi.org/10.1145/321043.321046).
- [CVXPY 1.7 documentation](https://www.cvxpy.org/version/1.7/), [Clarabel paper](https://arxiv.org/abs/2405.12762), [OSQP paper](https://arxiv.org/abs/1711.08013), [SciPy MILP documentation](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.milp.html), [OR-Tools TSP guide](https://developers.google.com/optimization/routing/tsp).
- Fisher, Iris data. [UCI dataset and CC BY 4.0](https://doi.org/10.24432/C56C76). This repository uses the sklearn-bundled version, recorded by its installed package version and saved numeric arrays; UCI documents historical transcription corrections.

Links support algorithm / data attribution. Runtime package versions and source hashes in each run record identify the actual implementation used; web documentation alone is not a claim that the measured stack is the newest version.
