# Scope and limitations

- **Recommendation:** MovieLens 100K is a historical explicit-rating benchmark, not modern online implicit recommendation. This study measures rating RMSE / MAE, not ranking, causal lift, user fairness or an online service. It uses no demographic attributes. Degree-regularized rank 32 models can overfit; the initial ALS failure is retained. Hyperparameter search uses validation; the fixed test is reused across the initial and extended benchmark. Three fits and a conditional user bootstrap do not support broad superiority claims. Learned factors and raw ratings remain private; local retraining and checkpoint inference are supported.
- **Routing:** textbook variants can be weak. The budgets count distance-edge work but not all operations; OR-Tools has a separately disclosed wall-clock budget and timing variability. The integer lower bound certifies a lower bound, not necessarily optimality. Published-optimum matches establish these individual instance lengths only. A route plot uses a declared fixed seed rather than silently picking a visually favorable fit.
- **Convex applications:** numerical tolerances matter. Original blending bounds require a physical log-convex assumption, not measured predictions. The evacuation model allows signed flow and within-slot forwarding; it is not a calibrated disaster simulator. The risk program allows short positions and can have very large gross exposure, especially at gamma 0.1; this is reported directly. No portfolio market data, transaction costs or predictive finance claim is included.
- **First order:** synthetic data enable exact checks but do not establish application-scale performance. Nuclear and biased factorization objectives differ. Exact SVD and ADMM factorizations have substantial setup / step costs. Newton and CG use curvature unavailable to plain gradient descent. Poisson zeros can produce infinite strict predictive likelihood; the added count floor is explicitly disclosed.
- **Spectral:** QR is an educational dense symmetric algorithm rather than a replacement for LAPACK. Schur is a named SciPy reference. SVD parameter ratios do not describe actual file compression, and PSNR uses a declared160 dB ceiling. Iris PCA illustrates geometry, not a modern classification benchmark.

- **Primal–dual imaging:** fixed penalties on one attributed photograph and one procedural image, each with three synthetic noise draws. Periodic boundaries can create wraparound. The feasible gap certifies only the stated optimization objective; lower optimization error need not improve true-image PSNR. Small cone oracles solve separate crops.
- **Adaptive search:** sixteen trials per strategy/seed, eight shared random startup trials, forty epochs and validation epoch selection. This is a constrained small search, with varying rank/compute and reuse of the earlier rating split. TPE does not outperform random search in the measured mean test score. Partial sampler continuation is rejected; complete campaigns skip unchanged.
- **Interactive views:** measured finite presets and stored images, alongside clearly labeled live domain inequalities. The tour map displays only final routes. Browser feasibility shading is a rasterized slice, not a conic solver or numerical proof.

All figures summarize actually computed evidence. This is a locally validated research reference release. Hosted CI, deployment at scale and an independent external replication are not claimed to have run.
